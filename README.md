# Wallet Service

## Запуск

Нужны только Docker и Docker Compose.

```bash
docker compose up --build
```

Приложение и база поднимаются вместе. Настройки читаются из файла `config.env`.
После старта сервис доступен по адресу `http://localhost`.

## Конфигурация

Все переменные окружения лежат в `config.env`:

| Переменная | Описание | Пример |
|---|---|---|
| `APP_PORT` | Порт HTTP-сервера | `80` |
| `POSTGRES_USER` | Пользователь БД | `wallet` |
| `POSTGRES_PASSWORD` | Пароль БД | `wallet` |
| `POSTGRES_DB` | Имя БД | `wallet` |
| `DB_HOST` | Хост БД | `database` |
| `DB_PORT` | Порт БД | `5432` |

## API
### Пополнение / списание

`POST /api/v1/wallet`

```json
{
  "walletId": "11111111-1111-1111-1111-111111111111",
  "operationType": "DEPOSIT",
  "amount": 1000
}
```

- `walletId`: UUID кошелька
- `operationType`: `DEPOSIT` или `WITHDRAW`
- `amount`: положительное целое число

Успешный ответ `200 OK`:

```json
{
  "walletId": "11111111-1111-1111-1111-111111111111",
  "balance": 1000
}
```

### Получение баланса

`GET /api/v1/wallets/{walletId}`

Ответ `200 OK`:

```json
{
  "walletId": "11111111-1111-1111-1111-111111111111",
  "balance": 1000
}
```

### Коды ответов

| Код | Когда |
|---|---|
| `200` | Операция выполнена, баланс получен |
| `400` | Невалидный JSON или UUID, `amount <= 0`, неизвестный `operationType`, лишние поля в теле |
| `404` | Кошелёк не найден |
| `422` | Недостаточно средств |
| `500` | Внутренняя ошибка (детали пишутся только в лог) |

Формат ошибки:

```json
{ "error": "insufficient funds" }
```

## Структура

```
.
├── cmd/app/main.go            # точка входа, сборка слоёв, graceful shutdown
├── internal/
│   ├── config/                # чтение настроек из окружения / config.env
│   ├── domain/                # типы операций и ошибки
│   ├── handler/               # HTTP-хендлеры и юнит-тесты
│   ├── migrate/               # применение миграций при старте
│   └── repository/            # SQL-запросы и интеграционные тесты
├── migrations/                # SQL-миграции
├── Dockerfile
├── docker-compose.yml
└── config.env
```

## Миграции

Миграции (`golang-migrate`) применяются автоматически при старте приложения. Повторный запуск применяет только новые файлы.

## Тесты

Тесты хендлера не требуют БД. Тесты репозитория работают с реальным Postgres (настройки берутся из `config.env`, хост подставляется `localhost`) и удаляют созданные кошельки после себя.

Что проверяется:

- коды ответов и валидация входных данных (200, 400, 404, 422, 500);
- пополнение, списание, нехватка средств, отсутствующий кошелёк;
- 1000 параллельных пополнений одного кошелька дают ровно ожидаемый баланс, обновления не теряются.
